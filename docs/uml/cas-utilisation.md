# Cas d'utilisation

Acteur unique : Utilisateur

- Enregistrer une entrée d'argent
- Enregistrer une dépense (avec ou sans catégorie/note)
- Enregistrer une épargne manuelle
- Épargner un pourcentage lors d'une entrée
- Consulter le solde d'une période
- Consulter le total épargné
- Filtrer les mouvements par période
- Modifier un mouvement existant
- Supprimer un mouvement
