# Gestion de Dépenses

Application de suivi de dépenses personnelles (quotidien, hebdomadaire, mensuel, annuel), développée en Python dans le cadre d'une remise à niveau après une interruption professionnelle.

## Statut

🚧 Projet en cours de développement

## Objectifs

- Suivre mes dépenses au quotidien
- Visualiser des totaux par période et par catégorie
- Comparer les dépenses à un budget défini

## Stack technique

- Python 3.12
- SQLite
- pytest
- (Interface à venir)

## Installation

\`\`\`bash
git clone https://github.com/sylvain-kadio/gestion-depenses.git
cd gestion-depenses
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
\`\`\`
